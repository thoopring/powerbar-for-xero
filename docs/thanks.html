PowerBar for Xero

Thanks — let's switch Pro on.

It takes about thirty seconds.

Your licence key is on the confirmation screen you just saw, and in the receipt email sent to the address you bought with. It looks like XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX.
  1. Install the extension, if you have not already.
    Get PowerBar for Xero from the Chrome Web Store
  2. Open the settings page.
    Click the PowerBar icon in Chrome's toolbar, then All settings… If you do not see the icon, click the puzzle-piece icon and pin PowerBar.
  3. Paste the key and press Activate.
    The Pro section should change to Pro is active, and Custom invoice PDF filenames will unlock.
  4. Turn the feature on.
    Tick Custom invoice PDF filenames. Chrome will ask for permission to manage downloads — that is what lets PowerBar rename the file, and it is handed back if you switch the feature off.
  5. Try it.
    Open any invoice in Xero and click Print PDF. The download should arrive as INV-0042 - Acme Ltd.pdf instead of Invoice INV-0042.pdf.

Good to know

  • One licence covers up to three browsers. Freeing a slot is one click: Remove from this browser on the settings page.
  • You can change the filename pattern — the default is {number} - {contact}.pdf.
  • Pro keeps working for a week without a connection, so a flaky network never locks you out mid-job.

Open an issue at github.com/thoopring/powerbar-for-xero/issues, or reply to your receipt email. If Pro is not what you hoped for, the refund policy is thirty days, no questions.
